# Dornier Aries 2 ROI 계산기 (산부인과 도입 제안용)

원장이 치료 모델·월 신규 환자·수가·결제 방식을 입력해 도입 경제성을 확인한다.
빌드·서버·로그인·DB 없는 정적 사이트(HTML+CSS+JS). 폰/PC 지원. 데이터는 브라우저(localStorage)·공유 링크·JSON 파일에만 담긴다.

## 파일 (역할 분리)
| 파일 | 역할 |
|---|---|
| `models.js` | **데이터** — 확인된 공급 조건, 프로토콜 17종(타수·횟수·간격·Level·Hz·근거·경고) |
| `calc.js` | **계산 엔진** — DOM 없는 순수 함수. 월별 시뮬레이션·목표 회수 역산 |
| `app.js` | **화면** — 입력·그래프·저장·JSON·출력 (계산식 두지 말 것) |
| `calc.test.js` · `calc.fuzz.js` | 엔진 검증. `node calc.test.js`(ALL PASS) · `node calc.fuzz.js`(무작위 3000회 불변식; 교체비 덩어리 지출 때문에 회수 시점이 0.05개월 늦어지는 1건 안팎은 정상) |
| `version.json` | 새 버전 알림 |

## 용어 (섞어 쓰지 말 것)
프로그램 계약 총액(계약 기준) / 시술 매출(치료 시점) / 실제 수납액(결제 방식별 현금) / 교체비 상당액(적립, 현금 아님) /
교체 현금지출(소진 시점 실제 지출) / 공헌이익(시술 매출−변동비) / 운영 후 공헌이익(−고정 운영비) /
월 현금흐름 = 수납액 − 추가 변동비 − 고정 운영비 − 교체 현금지출. **회수기간 = 누적 현금흐름이 0 이상이 되는 달.**
장비·교체비는 VAT 포함 금액 그대로 사용(수가와 혼용 안 함).

## 프로토콜 (출처: "Aries 2프로토콜.pptx", 17종 전부 반영)
산부인과 11종: 피부·피하조직 섬유화 / 결절성 섬유화·유착 / 비후성 흉터(타수=면적㎠×100) / 림프부종(상지) / 림프부종(하지) / 셀룰라이트 / 외음부통 / 성교통 / CPPS(산부인과) / SUI / OAB
비뇨기과 참고 6종: ED Mild / ED Moderate·Severe / CPPS Perineal / CPPS Trigger point / 페이로니병 Acute / 페이로니병 Stable
- 자료에 한 값만 있으면 고정(화면에서 못 고침), **범위로 적힌 값만 범위 안에서 선택**(예: 간격 1~2주, 페이로니 Stable 3,000~5,000타·8~12회).
- 자료에 없어 임시로 둔 값은 `assumed` 로 표시(현재 없음).
- PPT 에 적힌 값(타수·횟수·간격·Level·Hz)은 **확정값**이다. 근거 문구('내부 검토 값', 상지 외삽 등)는 근거란에만 표시한다.
- ED·CPPS Trigger point 치료 간격은 사용자 지정으로 **주 1회(7일)** (PPT에는 ED '8일 초과 시 연속성 저하'만, Trigger point 간격은 없음).
- 경고(`warn`)는 비후성 흉터 면적(병원별 입력, 기본 15㎠ 예시)만 남음.
- ⚠ 자료에 없는 수치를 만들거나 고치지 말 것. 자료가 바뀌면 `models.js` 만 고친다. 불러온 링크·JSON 의 프로토콜 값은 범위 밖이면 무시된다(`sanitize`).

## 확인된 조건 vs 가정값
확인: 공급가 88,000,000 / 교체비 15,000,000 / 보장 수명 2,000,000타 → 7.5원/타 (VAT 포함)
가정: 타당 수가(검토 60~80원, 확정 아님), 결제 방식, 분할 횟수, 운영비, 환자 수

## 결과 화면 용어 (원장님 화면 기준)
예상 장비 투자금 회수기간(= 월별 누적 현금흐름이 0 이상이 되는 달) / 핵심 지표 4개: 월 예상 시술 매출(=revenue) · 월 예상 운영 잉여(=afterFixed, 순이익 아님) · 월 예상 치료 건수(=sessions) · 월 신규 환자 수(모델별 단순 합산) — 앞 3개는 '환자 수가 일정하게 유지되는 안정기' 가정(R.steadyMonth).
'상세 경제성 분석'(접기·펼치기): 월 신규 프로그램 계약 총액 · 월 실제 수납액 · 월 공헌이익 · 어플리케이터 교체비 상당액 및 기타 변동비 · 추가 고정 운영비.
각 항목 ⓘ 는 `drawTips()` 가 현재 입력값으로 만드는 설명이며, 시술 매출↔실제 수납액 차이 설명(`explainGap()`)은 결제 방식과 월별 계산 결과만 근거로 쓴다(계산으로 확인되지 않는 원인은 쓰지 않음). 계산식은 calc.js 에 그대로 있고 이 화면 개선에서는 바꾸지 않았다.
